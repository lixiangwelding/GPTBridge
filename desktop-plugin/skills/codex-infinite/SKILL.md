# codex无限

场景名称：个人 MCP 本地开发与交付。
主要功能：读写本机工作区、执行受管命令、恢复持久任务，文档直接落本地。

先调用 server_info 确认实际工作区和运行版本，再用 task_open 创建或恢复明确的 task_id。命令与写入带 task_id、稳定 request_id；补丁先读文件并带 expected_hashes。同文件冲突重读合并，不回滚整仓或覆盖他人修改。

文档和生成文件直接写入已确认的本地工作区。优先遵守项目现有输出路由，无既有路由再用 docs/deliverables。写后核验存在性与内容，最终返回绝对路径；没有要求下载时不以云端附件替代本地交付。不得把预览、失败、删除或仅存在云端的文件说成本地文件。

长命令查询原 job，不重复提交未知结果，不关闭其他会话。结束前 task_checkpoint 保存实际进度与未验证项。安装版本、实际监听版本、插件目录识别和输入框可见性分别核验，不互相代替。
