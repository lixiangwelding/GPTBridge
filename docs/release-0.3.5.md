# 0.3.5：高并发恢复与可观测性

日期：2026-09-23。基线：个人仓库 main / `369baf124b4baf14c61593c40d261dbb23ca940d`。本版只修改个人 MCP，不修改外层业务仓库、业务配置或旧版 MCP。

## 日志事实与归因边界

2026-09-23 03:40 UTC 的只读审计，覆盖此前 48 小时，保留样本共 9,544 次工具调用，未触发 20,000 条截断。其中 142 次 `RESOURCE_BUSY`、107 次 `POLICY_REJECTED`。`search_text` P95 为 1,038ms，最长 36,066ms。这里的错误包括合理拒绝、旧版本记录和业务命令非零退出，不等于这些次数都是 MCP 缺陷；耗时包含客户端要求的等待，也不是子进程运行时长。

当前连接已实际暴露 33 个工具及 request_id / expected_hashes；不能再把早前的 26/33 客户端目录差异算作本版新修复。调查时的运行库没有失联作业堆积，因此下面的崩溃恢复缺陷来自真实代码和隔离复现，不声称当时已经发生队列事故。

## 修复与功能清单

| 项目 | 原行为或缺口 | 0.3.5 行为 |
|---|---|---|
| 饱和队列恢复 | 32 条失联 queued/running 记录会永久拒绝新任务 | 满队列时在写事务外检查最多 32 条活跃记录；遵守 alive 锁与启动宽限期，只把确实失去监督的作业标为 unknown，重新检查容量一次 |
| 完成任务回执 | task 完成检查先于幂等查询，原 request_id 也被拒绝 | 先核原回执与输入哈希；已完成任务仍可读取旧结果，新请求继续拒绝。完成检查与新作业插入在同一事务内 |
| 启动作业目录失败 | 登记 queued 后准备目录失败，可能留下陈旧记录 | 保存 spawn_failed 终态，明确命令未启动；不伪装成功 |
| 事件分页 | 显式请求 10 条仍被隐藏上限截成 3 条 | 遵守 1–100 的显式 limit；省略时保持原有轻量默认 |
| task/job 对应关系 | 同时传入互相矛盾的 ID，仍返回该 job | 返回 JOB_TASK_MISMATCH；仅传 job_id 的原用法不变。这是防止会话混用，不是跨用户权限隔离声明 |
| 压力快照 | 只能看到固定并发上限 | server_info 增加 runtime_pressure：排队/运行/构建数量、入队余量、最多 8 条样本、心跳年龄和等待原因；不读取原命令或输出，不自动改状态 |
| 等待原因与退避 | 只能看到 queued，固定 100ms 同步争锁 | 区分 source、resource、heavy_capacity、command_capacity；20ms 起步退避，单次队列睡眠不超过 266ms，心跳更新最多每秒一次。数据库争用仍可能额外增加延迟 |
| 耗时与输出 I/O | 缺少排队/执行区分；两个输出预览重复读元数据 | 输出预览共用一次有界 output.json 读取，单个元数据文件最多读取 16KiB+1；增加 timing。元数据缺失/损坏时用 null，保留真实输出与退出结果 |
| 脱敏诊断 | 需要临时写 SQL，容易误把合理拒绝当故障 | scripts/diagnose_personal.py 输出时间窗口、采样截断、错误类别及 P50/P95/P99；只读打开审计库，限制条数与 SQL 时间，不导出输入、输出、聊天原文或凭据 |

`queue_wait_ms` 指从登记到子进程开始的时间，包含启动准备；`worker_duration_ms` 是 worker 已保存的测量，不是 CPU 时间。压力快照反映数据库记录，不等于操作系统实际持有的许可数量；心跳老不能单独证明进程死亡。没有宣称 CPU 占用或端到端吞吐达到某个未测量的改善比例。

## 日常诊断与升级

```bash
python3 scripts/diagnose_personal.py --hours 12
python3 scripts/diagnose_personal.py --hours 48 --limit 20000 --output .artifacts/diagnostics/new-report.json
python3 scripts/selftest_personal.py --suite all
python3 scripts/upgrade_personal.py
python3 scripts/upgrade_personal.py --apply
```

诊断输出文件只允许新建在本仓库 `.artifacts`，默认权限 0600，不覆盖旧回执。`--audit` 可指定实际审计库；默认路径针对 macOS 个人版。

安装脚本保留旧应用备份、校验配置哈希与新制品原生解析，只替换当前用户的个人版应用。磁盘替换不自动意味着运行进程已经更新，最终必须核验实际 `server_info.version`、33 工具合同、压力字段和新任务/回执链路。安装与运行验收回执分别保留，不能互相代替。
