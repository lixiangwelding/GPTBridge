# 个人版需求与验收

## 范围
基于已核上游 8e76bd06 的独立个人仓库实施；不使用 worktree；不停止、重启、修改现有服务或生产配置。个人版首次运行与旧版并存。

## 功能要求
- FR-1：用户无需粘贴历史长提示词。initialize 提供简短统一约定；task 工具以目标创建/恢复任务，原历史工具保持兼容；未传入聊天正文不得宣称已自动捕获。
- FR-2：同目录多任务并行，任务显式绑定而非 workspace 唯一 active；落盘采用跨进程短锁和文件 SHA 前置条件；旧补丁拒绝，不恢复全仓旧快照。
- FR-3：步骤和实际执行回执持久化，区分 running、成功、失败、结果未知。重复请求幂等；同 key 不同内容拒绝。新对话以 task_id 恢复。
- FR-4：非交互命令由独立 worker 运行，MCP 连接/进程退出不丢终态；进程崩溃与主机重启不承诺指令级续跑，结果未知必须核查，不能自动重放。
- FR-5：命令并发/输出/排队有界；共享资源排队，独立读任务并行；所有执行继续经过既有权限和路径校验。
- FR-6：个人应用标识、数据、日志隔离；配置继承仅复制，关闭自动启动/隧道并重新分配本地端口，不覆写原件；密钥和运行数据不提交。
- FR-7：脚本测试真实覆盖并发、冲突、断点、断线/重启、幂等、超时、取消、输出和配置隔离；提交只含本轮源码，推到用户自有仓库。

## 非功能要求
SQLite 短事务；锁只覆盖必要资源；每条输出分页不超过 1MiB，单命令每流默认最多保留 8MiB；任务状态与业务验收分层；保持历史工具协议兼容。

## 排除
不自动运行独立 LLM 编码循环；不承诺自动读取 ChatGPT 未传入对话；不强制 worktree；不自动发布线上或更新已运行服务；不以文件锁冒充 OS 沙箱。
