# 0.3.7：版本化 Python 虚拟环境与只读诊断

本次用户明确授权直接修复个人 MCP、commit/push、安装并恢复原虚拟环境诊断。

## 变更

- 修复策略接受 `python3.x`、执行器却只枚举固定白名单身份的不一致。比较入口名与真实文件名在宿主 PATH 上的**精确规范路径**；仍拒绝工作区外冒名程序，启动时仍保留虚拟环境入口。
- 将只读 `lsof` 纳入个人版基础诊断；没有加入 kill、没有取消工作区边界或参数校验。
- 新增 `scripts/restart_personal.py`，用于已有个人 LaunchAgent 的显式空闲升级。核对配置、二进制和 launchd 身份，预热候选，确认其他任务与 RPC 空闲后只重载唯一已登记服务；不重启业务服务、隧道或 ChatGPT Desktop。空闲连接可能重连，不声称零连接中断。

## 回归与交付

新增四项执行器回归先红测：可信 Python/venv/权限预检三个失败，外部冒名程序拒绝通过。新增六项 LaunchAgent 身份及并发保护测试。最终测试、提交、安装和原环境 HTTP 结果以本次 `docs/venv-lsof-2a1b31c6/` 交付回执为准，未验证项不写成通过。
